# 关于 2.x 分支的功能

由于 3.x 分支的升级，wheel 包经历了重构，导致部分模型和功能与旧版分支不再兼容。为了使得依赖于 2.x 分支功能的用户能够继续使用这些功能，我们在此目录中保留了与 2.x 分支相关的代码。
